# Visual Scan Report

A beginner-friendly cybersecurity project that generates a visual scan report using Python.  
It focuses on visualizing open ports, risk levels, and generating structured HTML reports.

---

## 🚀 Features

- Open port visualization
- Risk level calculation based on port exposure
- Interactive Plotly charts
- HTML report generation using Jinja2
- Clean, structured output for analysis

---

## 🛠️ Technologies Used

- Python 3.x
- Plotly
- Jinja2
